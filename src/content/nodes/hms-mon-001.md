## Description

For a local system on a connected base $B$ with chosen basepoint $b$, monodromy is a representation

$$\rho:\pi_1(B,b)\longrightarrow\operatorname{Aut}(V_b).$$

In a geometric family, the local system can arise from cohomology. The base and singular locus must be specified before computing matrices.

## Why it matters

Monodromy records how period data change under continuation and can expose structure invisible in one fiber.
