## Definition

In a $k$-linear triangulated category, an object $E$ is exceptional if $\operatorname{Hom}(E,E)=k$ and $\operatorname{Hom}(E,E[i])=0$ for $i\ne0$. An ordered collection $(E_1,\ldots,E_r)$ is exceptional if each object is exceptional and

$$\operatorname{Hom}(E_j,E_i[m])=0 \quad (j>i,\ m\in\mathbf Z).$$

It is **full** when these objects generate the entire category as a thick triangulated subcategory.

## Why it matters

Fullness says that the chosen objects capture the entire category; exceptionality alone does not.
