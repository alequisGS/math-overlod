## Description

For $n\ge1$, the weighted projective plane is

$$\mathbf P(1,1,n)=\operatorname{Proj} k[x,y,z],\qquad \deg(x,y,z)=(1,1,n).$$

The corresponding quotient stack is a different object from the coarse scheme. Any categorical calculation must specify which one is meant. No categorical-genus values are asserted here.

## Why it matters

A parameterized family provides a natural test for whether a proposed invariant captures stable structure.
